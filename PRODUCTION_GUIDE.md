# Blue Black Beige — Production Deployment Guide

## Step 1 — Install new dependencies

```bash
cd /Users/manishraj/Downloads/code-on-time
npm install
```

This installs `resend` (email) and `zod` (validation).

---

## Step 2 — Set up Resend (email backend)

1. Go to **https://resend.com** → Sign up free
2. Click **Domains** → Add Domain → type `blueblackbeige.in`
3. Resend will give you **DNS records** to add in GoDaddy:
   - An MX record
   - Two TXT records (for SPF and DKIM)
4. In GoDaddy → My Products → DNS → add those records
5. Wait 10–30 minutes → click **Verify** in Resend
6. Go to **API Keys** → Create API Key → copy it

## Step 3 — Create your .env.local file

```bash
cp .env.example .env.local
```

Then open `.env.local` and fill in:

```
RESEND_API_KEY=re_xxxxxxxxxxxxxxxxxxxx
CONTACT_TO_EMAIL=nayan@blueblackbeige.in
CONTACT_FROM_EMAIL=hello@blueblackbeige.in
NEXT_PUBLIC_WHATSAPP_NUMBER=91XXXXXXXXXX
NEXT_PUBLIC_SITE_URL=https://blueblackbeige.in
```

**WhatsApp number format:** Country code + number, no spaces or +
Example: India (+91) 98765 43210 → `919876543210`

## Step 5 — Deploy to Vercel

```bash
# Install Vercel CLI (one time)
npm i -g vercel

# Deploy
vercel

# Follow prompts:
# - Link to existing project? No → create new
# - What's your project name? blue-black-beige
# - Which directory? ./  (just press Enter)
# - Override settings? No
```

After first deploy, Vercel gives you a `.vercel.app` URL.

### Add environment variables to Vercel:

```bash
vercel env add RESEND_API_KEY
vercel env add CONTACT_TO_EMAIL
vercel env add CONTACT_FROM_EMAIL
vercel env add NEXT_PUBLIC_WHATSAPP_NUMBER
vercel env add NEXT_PUBLIC_SITE_URL
```

Or add them in the Vercel dashboard → Settings → Environment Variables.

Then redeploy:
```bash
vercel --prod
```

---

## Step 6 — Connect blueblackbeige.in (GoDaddy → Vercel)

1. In Vercel → Project → Settings → Domains → Add `blueblackbeige.in`
2. Also add `www.blueblackbeige.in` (Vercel will auto-redirect to root)
3. Vercel shows you two DNS values — go to GoDaddy:

**GoDaddy DNS settings:**

| Type | Name | Value |
|---|---|---|
| A | @ | 76.76.21.21 |
| CNAME | www | cname.vercel-dns.com |

4. Delete any existing A record for `@` first
5. Wait 10–30 mins → Vercel shows ✓ green

SSL (HTTPS) is automatic and free via Vercel.

---

## Step 7 — Google Search Console

1. Go to **https://search.google.com/search-console**
2. Add property → URL prefix → `https://blueblackbeige.in`
3. Download the HTML verification file → place in `/public/`
4. Or copy the meta tag value → paste into `app/layout.tsx`:
   ```
   verification: { google: "your_token_here" }
   ```
5. Submit sitemap: `https://blueblackbeige.in/sitemap.xml`
